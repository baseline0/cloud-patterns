Scenario 1: Static Website Hosting

Welcome to Your S3 Website!

This static website is hosted on Amazon S3, served directly from CloudFront (or S3 static hosting).

Architecture

User → S3 Bucket → index.html, style.css
                    ↓
            Public Read Access via Bucket Policy

Key Concepts

  • S3 Bucket: Cloud object storage (like a distributed hard drive)
  • Bucket Policy: JSON-based access control (who can read what)
  • Static Website Hosting: S3 serves index.html for / requests
  • Serverless: No servers to manage, you only pay for storage
  • Global Distribution: Content served from AWS edge locations
